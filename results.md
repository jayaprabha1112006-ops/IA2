# CNN vs Vision Transformer Comparison

## 1. Experimental Setup

The CNN and Vision Transformer (ViT) were implemented and evaluated on the same CIFAR-10 image classification dataset.

CIFAR-10 contains 50,000 training images and 10,000 test images across 10 classes. Each image has a resolution of 32 × 32 pixels with 3 RGB channels.

Both models were trained for 5 epochs using the same dataset and evaluated on the same test set.

---

## 2. Image Representation

### CNN

The CNN processes an image using convolutional filters. The convolutional layers extract local visual features such as edges, textures and patterns. As the image passes through deeper layers, increasingly complex features are learned.

For visualization, the feature maps produced by the convolutional layers were examined before the final adaptive pooling layer.

### Vision Transformer

The Vision Transformer divides the input image into fixed-size patches.

For a 32 × 32 CIFAR-10 image with a patch size of 4 × 4, the image is divided into:

32 / 4 = 8 patches along each dimension

Therefore:

8 × 8 = 64 image patches

Each patch is converted into an embedding and treated as a token. Positional embeddings are added so that the model retains information about the location of each patch. These tokens are then processed by transformer encoder layers.

### Representation Comparison

The CNN uses a hierarchical representation based on local convolutional features, whereas the ViT represents the image as a sequence of patch tokens.

The representation visualization shows the difference between the spatial feature maps generated by the CNN and the patch-based representation used by the ViT.

## 3. Classification Performance

| Model | Test Accuracy |
|-------|---------------|
| CNN | 64.98% |
| ViT | 66.72% |

The Vision Transformer achieved a test accuracy of 66.72%, while the CNN achieved 64.98%.

Therefore, the ViT achieved an improvement of:

66.72 - 64.98 = 1.74 percentage points

The ViT therefore provided slightly better classification performance in this experiment.

---

## 4. Computational Behavior

| Model | Parameters | Inference Time |
|-------|------------|----------------|
| CNN | 94,538 | 7.10 seconds |
| ViT | 809,098 | 15.78 seconds |

The Vision Transformer contains significantly more parameters than the CNN.

Parameter ratio:

809,098 / 94,538 ≈ 8.56

Therefore, the ViT has approximately 8.56 times more parameters.

The ViT also required more time for inference:

15.78 / 7.10 ≈ 2.22

Therefore, the ViT inference time was approximately 2.22 times higher than that of the CNN.

This indicates that the ViT provided a small accuracy improvement at the cost of substantially higher computational requirements.

---

## 5. Overall Comparison

The CNN and ViT use fundamentally different approaches to image representation.

The CNN extracts hierarchical local features using convolutional operations. This makes it computationally efficient and suitable for image classification tasks.

The ViT divides the image into patches and processes them as tokens using transformer encoder layers. This allows the model to learn relationships between different image patches.

In this experiment, the ViT achieved slightly higher classification accuracy than the CNN. However, the ViT had approximately 8.56 times more parameters and approximately 2.22 times higher inference time.

Therefore, the results demonstrate a trade-off between classification performance and computational efficiency. The CNN was more computationally efficient, while the ViT achieved slightly better classification performance.

---

## 6. Conclusion

The experiment successfully implemented both a CNN and a Vision Transformer for the same CIFAR-10 image classification task.

The CNN achieved 64.98% test accuracy, while the ViT achieved 66.72%. Although the ViT performed slightly better, it required considerably more computational resources.

The experiment demonstrates that CNNs provide efficient hierarchical image representations, while Vision Transformers use patch-based token representations and can achieve competitive classification performance with greater computational cost.
